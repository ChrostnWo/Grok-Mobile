# Quick actions

Four chips sit above the reply on the phone sheet and the desktop sidebar.

- **Summarize** — the open note, not a stray selection
- **Rewrite** — the selection, or the context already loaded
- **Fix grammar** — the selection, or the context already loaded
- **Continue** — text before the cursor

A chip fills the prompt and sends.

Insert, Replace, and Copy still use the raw Markdown, not the rendered HTML.

Finished replies render as Markdown (headings, lists, code). While tokens are arriving, the reply stays plain text. Phone waits for the full reply. Streaming is laptop-only.
