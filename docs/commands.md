# Commands

Open the command palette, or tap the sparkles ribbon icon.

| Command | What it does |
| --- | --- |
| Open Grok chat | Opens the sidebar or sheet |
| Open Grok sidebar | Opens the sidebar |
| Ask Grok about selection | Sends the selection |
| Ask Grok about this note | Sends the open note |
| Summarize this note | Opens the sheet or sidebar with the note loaded and sends |
| Continue writing from cursor | Uses the text before the cursor |
| Rewrite selection | Rewrites the selection |
| Fix grammar of selection | Fixes grammar in the selection |
| Imagine something new | Image from a prompt you type |
| Imagine from this note | Drafts a prompt from the note, then generates |
| Imagine from this folder | Drafts a prompt from up to 8 notes in the folder |
| Imagine from vault sample | Drafts a prompt from the 12 newest notes |
| Test xAI API key | Checks the key in settings |

On a laptop, select text → right click → **Ask Grok about selection**.

After a reply: Insert, Replace, or Copy. Those write the Markdown source, not the rendered HTML. Summarize: tap Insert to put the summary in the note.
