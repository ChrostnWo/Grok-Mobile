## What this plugin is

Grok Notes writes inside the vault. It is not a coding agent and it does not shell out to the Grok CLI.

- Chat about the open note or a selection
- Summarize, rewrite, fix grammar, continue from the cursor
- Imagine a jpg from a new prompt, the note, the folder, or a 12-note vault sample
- Insert or replace the Markdown reply in the note

Plugin id: `grok-mobile`. Folder name must stay `grok-mobile`.
