# Security

## Report a vulnerability

Open a private security advisory on this repo, or email the address on the GitHub profile of ChrostnWo. Do not post an API key in a public issue.

## Keys

The xAI key lives in the vault at `.obsidian/plugins/grok-mobile/data.json`. Treat that file as a secret. Do not commit it. Do not put the key in a note that syncs to a public repo.

## Network

Chat and Imagine call `https://api.x.ai` only when you send or generate. Review the request text before you send a vault sample. A vault sample is the 12 newest notes.
